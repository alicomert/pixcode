NanoClaw API quick start

Use the maintained NanoClaw task API for multi-CLI runs and schedules. The older /api/orchestration/workflows/* routes were retired in v1.55; use the production agent loop for admin review and CI automation.

Engine status GET /api/nanoclaw/status
Run an agent POST /api/nanoclaw/run
Schedule a task POST /api/nanoclaw/tasks
Full cookbook GET /api/nanoclaw/help 
curl -X POST -H "X-API-Key: px_..." \
  -H "content-type: application/json" \
  -d '{"prompt":"summarize git status","agentType":"codex","projectId":"my-app"}' \
  /api/nanoclaw/run
